# A.Star Decoration & Rental Services

This is the official digital portfolio for A.Star Decoration & Rental Services. We provide professional event decoration and equipment rental services based in Kano State, Nigeria. Our focus is on creating elegant environments for all types of occasions.

---

## About

A.Star Decoration & Rental Services is committed to delivering quality design and reliable rental solutions. We serve clients across Kano, ensuring that every event is styled to meet professional standards and personal preferences.

## Project Setup

To run this project locally, follow these instructions:

1. Clone the repository:
git clone [https://github.com/yourusername/astardecoration.git](https://www.google.com/search?q=https://github.com/yourusername/astardecoration.git)
2. Navigate to the project directory:
cd astardecoration
3. Install dependencies:
npm install
4. Start the development server:
npm run dev
5. Open http://localhost:3000 in your browser.
